🚀 COMEÇAR (Opção 1: Docker - Mais fácil)
═══════════════════════════════════════════════════════════════════════════════

1. Pré-requisitos:
   • Docker e Docker Compose instalados
   • Node.js 18+
   • Git

2. Comandos:
   
   $ cd energia-agua-painel
   
   $ docker-compose up -d
   # Aguardar postgres estar pronto
   
   $ npm install
   
   $ npm run db:migrate -w backend
   $ npm run db:seed -w backend
   
   $ npm run dev
   # Backend: http://localhost:3000
   # Frontend: http://localhost:5173

3. Login:
   Email: admin@energia-agua.com
   Senha: senha123

🛠️ COMEÇAR (Opção 2: Manual - Mais controle)
═══════════════════════════════════════════════════════════════════════════════

1. Instalar PostgreSQL
   • Windows: https://www.postgresql.org/download/windows/
   • Mac: brew install postgresql@15
   • Linux: sudo apt install postgresql

2. Criar banco de dados
   $ psql -U postgres
   > CREATE DATABASE energia_agua_2026;
   > \q

3. Clonar e configurar
   $ cd energia-agua-painel
   $ npm install
   $ cp backend/.env.example backend/.env

4. Migrar banco
   $ npm run db:migrate -w backend
   $ npm run db:seed -w backend

5. Iniciar
   $ npm run dev

📡 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

Autenticação
  POST   /api/auth/register        Criar novo usuário
  POST   /api/auth/login           Fazer login
  POST   /api/auth/verify          Verificar token

Consumo
  GET    /api/consumo              Listar (com filtros: ano, mes, tipo)
  GET    /api/consumo/:id          Obter um específico
  POST   /api/consumo              Criar novo
  PUT    /api/consumo/:id          Atualizar
  DELETE /api/consumo/:id          Deletar

Fornecedores
  GET    /api/fornecedor           Listar
  GET    /api/fornecedor/:id       Obter um
  POST   /api/fornecedor           Criar
  PUT    /api/fornecedor/:id       Atualizar
  DELETE /api/fornecedor/:id       Deletar

Relatórios
  GET    /api/relatorio/consumo-por-local       Por local
  GET    /api/relatorio/consumo-por-mes         Por mês
  GET    /api/relatorio/resumo                  Resumo geral
  GET    /api/relatorio/comparacao-anual        Comparação anual

➜ Veja API_EXAMPLES.md para exemplos completos com curl/Postman
